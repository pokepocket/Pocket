4계정 넣기

부계정은 로그인 파일(xml)로 관리해요. 둘 중 편한 방법으로 넣으면 돼요.

방법 A · PTCGPB 쓰던 사람

  1. PTCGPB 폴더의 Accounts\Saved\… 안에 있는 .xml 파일들을 복사해요.
  2. 매크로 왼쪽 메뉴 부계 계정 폴더를 누르면 폴더가 열려요. 거기 붙여 넣으면 끝.

방법 B · 인스턴스에 이미 로그인된 계정

  1. 그 계정이 로그인된 인스턴스를 켜 두고, 왼쪽 메뉴 계정 꺼내기·넣기를 열어요.
  2. 인스턴스를 고르고 ⬇ 이 인스턴스 계정 꺼내기 → 로그인 파일이 저장돼요.
  3. 오른쪽 저장된 계정 목록에서 골라 → 부계관리에 넣기를 누르면 부계 폴더로 들어가요.
xml 파일 = 그 계정의 로그인 정보예요. 남한테 주면 그 사람이 계정을 그대로 쓸 수 있어요. 절대 올리거나 보내지 마세요.

5처음 켜기 · 인스턴스 고르기

  1. 쓸 MuMu 인스턴스들을 먼저 켜 두고 PocketMacro.exe를 실행해요.
  2. 위쪽 ⟳ 새로고침을 누르면 켜진 인스턴스가 표에 나와요. 위에 ADB 경로가 보이면 연결 OK.
  3. 왼쪽 부계관리를 눌러 부계관리 창을 열어요.
  4. 오른쪽 인스턴스 고르기에서 부계 돌릴 인스턴스를 체크하고 저장해요.

6모드 고르기 (리세 / 부계)

왼쪽 위 모드에서 하고 싶은 것만 고르면 돼요. 언제든 바꿀 수 있고, 돌고 있던 워커는 하던 일 끝나고 바뀐 모드를 따라가요.

모드하는 일이런 사람
리세 + 부계관리 (기본)부계를 돌리고, 깔 계정이 없어서 쉴 때 리세. 리세로 건진 계정도 부계로 같이 돌려요.둘 다 하고 싶은 사람
리세만계속 리세만 해요. 건진 계정은 Saved\리세에 모아만 두고 팩은 안 까요.새 계정 뽑기만 원하는 사람
부계관리만부계만 돌리고, 쉴 땐 인스턴스를 꺼 둬요. 리세는 안 해요.이미 계정이 있는 사람

모드에 따라 왼쪽 실행 버튼도 바뀌어요. 리세만이면 리세만, 부계관리만이면 부계관리만 보여요.

리세만 모드에서는 부계 폴더가 비어 있어도 돼요. 리세 창의 인스턴스 고르기 → ▶ 전부 시작 (30초 간격)으로 시작하면 끝.

7디스코드 알림 (선택)

좋은 카드(☆☆ 이상, 크라운, 이로치 등)가 나오면 디스코드로 알려 줘요. 안 쓰면 건너뛰어도 돼요.

  1. 디스코드 서버에서 채널 설정 → 연동 → 웹후크 → 새 웹후크 → 웹후크 URL 복사.
  2. 부계관리 창 오른쪽 디스코드 알림을 누르고 복사한 주소를 붙여 넣고 저장.
웹후크 주소도 남한테 보이면 아무나 그 채널에 글을 쓸 수 있어요. 캡처 올릴 때 가려 주세요.

8돌리기

부계관리 창에서 ▶ 전부 시작 (또는 골라서 ▶ 선택 시작). 이제 놔두면 돼요.

계정마다 뭘 하는지는 바로 아래 부계관리 기능에 다 적어 뒀어요.

알아서 고치는 것

  • MuMu가 멈춤(좀비): adb가 끊기거나 화면·게임이 응답 없으면 그 인스턴스만 끄고 다시 켜서 이어서 해요.
  • 워커가 죽거나 15분 동안 멈춤: 매크로 창이 켜져 있으면 알아서 다시 시작해요 (한 시간에 5번까지).
  • PC를 껐다 켜면: 자동으로 다시 시작하진 않아요. PocketMacro.exe 켜고 ▶ 전부 시작만 누르면 하던 데서 이어서 해요.
그래서 돌리는 동안엔 매크로 창을 끄지 말고 내려만 두세요.
안 쓰는 것: 팩 모래시계, 포켓 골드는 절대 안 써요. 깐 결과는 계정마다 기록돼요.

부계관리 창 아래 표에 계정마다 깐 것 / 안 깐 것 / 좋은 거 / 실패가 보여요. 행을 누르면 그 계정에서 나온 카드가 다 나와요.

쉬는 동안

  • 배틀 미션: 대여 덱 + 오토로 레슨 → 스텝 업 → 혼자서 랜덤 배틀(초급)을 해서 미션을 채워요. 보상은 다음에 그 계정 들어갈 때 받아요.
  • 스텝 업 깨기: 부계관리 창 체크박스를 켜 두면, 아직 안 깬 계정은 대여 덱으로 스텝 업 리스트를 깨요.
  • 리세: 모드가 「리세 + 부계관리」면 남는 시간에 리세를 돌려요.
  • 할 게 없으면 인스턴스를 꺼 두고, 다음 계정 차례 5분 전에 다시 켜요.

알림 · 기록

  • ☆☆ 이상, 크라운, 이로치, RGB 뮤가 나오면 디스코드로 알려 줘요. 어느 계정에서 뭐가 나왔는지 카드 ID도 같이 와요.
  • 팩 포인트 1250, 계정을 한 바퀴 다 돌았을 때도 알려 줘요.
  • 깐 카드는 계정마다 전부 기록돼서 부계관리 창 아래 표와 계정대장에 나와요.

절대 안 하는 것

  • 팩 모래시계 쓰기, 포켓 골드 쓰기, 숍에서 골드 사기
  • 트레이드 파워 「+」 충전, 아이템 쓰기

10리세

리세는 부계관리가 깔 계정이 없어서 쉬는 동안 같은 인스턴스에서 돌아가요 (리세만 모드면 계속 리세). 새 계정을 만들어 팩을 까 보고, 목표 카드가 나오면 계정을 남기고 아니면 지우고 다시 해요. 부계관리를 돌리고 있으면 따로 켤 필요 없어요.

  1. 왼쪽 리세를 눌러 리세 창을 열어요.
  2. 위쪽 버튼이 ■ 리세 끄기면 켜져 있는 거예요 (「켜짐 — 부계관리 워커가 깔 계정이 없어 쉴 때 리세를 돌립니다」).
  3. 목표 설정: 카드 이름을 일부만 쳐도 찾아 줘요. 고른 카드를 ↓ 목표에 넣기, 몇 장 나오면 달성인지 정하고 저장.
  4. 아래 체크박스로 뮤가 나와도 계정 보관, 크라운 보관, 스페셜 팩도 까기를 고를 수 있어요.
  5. 리세만 바로 돌리고 싶으면 ▶ 전부 시작 (30초 간격).
  • 남긴 계정은 부계계정\Accounts\Saved\리세로 들어가고, 그다음부터는 부계관리가 알아서 같이 돌려요.
  • 보관 계정 폴더에서 건진 계정 xml을 볼 수 있어요. 리세 창 아래에 판 기록, 최근 깐 팩, 맞은 카드가 나와요.
  • 팩은 목표 카드가 있는 팩으로 자동으로 골라요.
목표를 하나도 안 넣고 뮤·크라운 보관도 끄면 모든 계정을 버리게 되니 하나는 켜 두세요.

11계정대장 보기

왼쪽 계정 대장을 누르면 브라우저에 대장이 열려요. 누를 때마다 새로 만들어요.

  • 위쪽 검색창에 카드 이름(예: 피카츄)을 치면 그 카드 있는 계정만 남고, 몇 장인지 세 줘요.
  • 등급 버튼(크라운, ☆☆☆, 이로치 등)을 누르면 그 등급 이상만 보여요.
  • 팩포 칸은 팩 포인트예요. 1250이 되면 ☆☆ 한 장으로 바꿀 수 있어서 따로 표시돼요. 칸을 누르면 어느 팩 포인트인지 나와요.
  • 카드나 상태 칸을 누르면 언제 뽑았는지 같은 자세한 정보가 떠요.
대장 파일은 accounts\export\계정대장.html로 저장돼요. 남한테 보여 줄 땐 이 파일을 보내면 되는데, 계정 이름이랑 친구 ID가 들어 있으니 괜찮은지 먼저 확인하세요.

12멈추기

  • F8 또는 ■ 모두 중지: 전부 멈춰요. 지금 까는 팩까지는 끝내고 멈춰요.
  • 부계관리 창의 ■ 선택 중지: 고른 인스턴스만 멈춰요.
  • 다시 돌릴 땐 ▶ 전부 시작만 누르면 이어서 해요. 어디까지 했는지 기억해요.

13안 될 때

증상해 볼 것
위쪽 ADB 경로가 비어 있음 / 인스턴스가 안 나옴 MuMu 켠 다음 ⟳ 새로고침. 그래도 안 되면 macro_config.json을 메모장으로 열어 "adb_path"에 MuMu 설치 폴더의 adb.exe 경로를 넣어요. 예: "C:/Program Files/Netease/MuMuPlayerGlobal-12.0/shell/adb.exe" (역슬래시 대신 /)
계정 꺼내기에서 (adb 연결 안 됨)MuMu가 켜져 있는지 보고 메인 창 ⟳ 새로고침 후 다시 열기. 그래도 안 되면 인스턴스를 껐다 켜요.
계정 꺼내기에서 (루트 응답 없음)인스턴스 설정 → 개발자 옵션 → Root 권한 켜고 인스턴스 재시작. MuMu 화면 안에 「루트 권한 허용?」 창이 떠 있으면 허용. 그래도 안 되면 logs\root_check.log 파일 내용을 보내 주세요 (루트를 어떤 방법으로 시도했고 뭐라고 답했는지 적혀 있어요).
계정 꺼내기에서 (로그인 안 됨)그 인스턴스에 게임이 로그인된 적이 없어요. 게임을 켜서 홈 화면까지 들어간 다음 다시.
로그인이 안 되고 계속 실패그 인스턴스 설정에서 Root 권한이 켜져 있는지 확인하고 인스턴스를 재시작.
화면을 못 찾고 같은 데서 멈춤해상도가 540 × 960 (240 DPI)인지, 게임이 한국어인지 확인.
계정이 0개로 나옴xml이 부계계정\Accounts\Saved\부계 바로 안에 있는지 확인 (폴더 안의 폴더면 못 읽어요).
뭐가 잘못됐는지 모르겠음로그 폴더 열기 → 인스턴스별 폴더의 pack13.log 마지막 줄을 보면 거기서 뭘 하다 멈췄는지 나와요.
MuMu 하나에 RAM을 너무 적게 주면 게임이 자주 튕겨요. 인스턴스 여러 개 돌릴 땐 PC 사양 보면서 개수를 맞춰 주세요.
